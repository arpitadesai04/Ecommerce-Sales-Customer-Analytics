# E-Commerce Sales & Customer Analytics

## 📌 Project Overview

This project analyzes an e-commerce sales dataset to identify trends in **sales performance, profitability, customer behavior, product performance, and regional sales**.

The project uses **Python, SQL, and Power BI** to transform raw e-commerce data into meaningful business insights through data cleaning, exploratory data analysis, SQL queries, and an interactive dashboard.

---

## 🎯 Project Objectives

* Analyze overall sales and profit performance.
* Identify top-performing products and categories.
* Analyze sales trends over time.
* Understand customer segments and purchasing patterns.
* Compare sales performance across different regions.
* Identify profitable and less profitable product categories.
* Create an interactive Power BI dashboard for business analysis.
* Practice SQL queries commonly used in Data Analyst roles.

## 🧹 Data Cleaning

The dataset was cleaned using Python and Pandas.

Major preprocessing steps included:

* Checking dataset dimensions.
* Inspecting column names and data types.
* Checking for missing values.
* Identifying and removing duplicate records.
* Converting date columns into proper datetime format.
* Creating additional time-based features.
* Checking numerical columns for inconsistencies.
* Preparing a cleaned dataset for Power BI analysis.
